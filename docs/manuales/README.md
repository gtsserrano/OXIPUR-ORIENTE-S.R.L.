# Documentación del sistema OXIPUR

Esta carpeta contiene la documentación oficial correspondiente a la versión 1.0 desplegada en producción el 23 de julio de 2026.

## Documentos

- `ficha_tecnica_sistema_oxipur.pdf`: arquitectura, infraestructura, seguridad, persistencia, migración histórica, respaldos y validaciones técnicas.
- `guia_de_usuario_sistema_oxipur.pdf`: procedimientos paso a paso para todas las funciones visibles del sistema, diferenciados por rol.

## Mantenimiento

Los documentos deben actualizarse cuando cambien las pantallas, permisos, reglas operativas, arquitectura, modelo de datos o procedimientos de despliegue y respaldo.

No deben incluirse contraseñas, claves privadas, tokens ni otros secretos.
